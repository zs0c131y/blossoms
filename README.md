# 🌸 Blossoms Website

Welcome to the official Blossoms Website – a dedicated platform for Christ University's Blossoms event! This website showcases the spirit of competition, creativity, and celebration among various schools vying for the prestigious Blossoms Trophy.

## 📌 Live Website

[🔗 Visit Blossoms Website](https://blossomsbyc.netlify.app)

## ✨ Features

✅ **Event Overview** – Get all the details about Blossoms, including themes and schedules.  
✅ **Theme Highlights** – Explore the past and present themes, bringing unique storytelling each year.  
✅ **Leaderboard & Results** – Stay updated with school rankings and competition results.  
✅ **User-Friendly Design** – Clean and responsive UI for an engaging experience.  
✅ **Mobile & Desktop Compatibility** – Fully optimized for all devices.

## 🚀 How to Run Locally

Clone the repository:

```bash
git clone https://github.com/zs0c131y/blossoms.git
cd blossoms
```

Open the `index.html` file in a browser – no server setup required!

## SEO and motion maintenance

The site remains buildless HTML/CSS/JavaScript. AOS 2.3.4 is self-hosted in `assets/vendor/aos/`, with its MIT license included. Motion is progressively enhanced in `jsfile/motion.js` and respects reduced-motion settings. Navigation and content also work when animation libraries are unavailable.

After editing the event data in `jsfile/*_events.js` or results in `jsfile/results.js`, run `node scripts/prepare-seo.mjs` to refresh the committed HTML rules/results, page metadata, JSON-LD, `robots.txt`, and `sitemap.xml`. This optional maintenance command requires Node; serving or opening the finished site does not.

Canonical and social URLs use the existing public domain `https://blossomsbyc.netlify.app`. If the domain changes, update `origin` in `scripts/prepare-seo.mjs` and rerun it. The 2024-25 festival is archived; metadata must not imply that these dates are upcoming. After deploying, submit `/sitemap.xml` in the site's Google Search Console property and use URL Inspection to verify live indexing.
